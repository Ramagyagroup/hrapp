GPU_INFO collects GPU model, VRAM and driver version. Same test on every device.

GPU_VRAM >= 8 GB in GRAPHIC_DESIGNER_V2. Evaluated on the server against the result of GPU_INFO.

🔒 Security principle
✅ Allowed
AI / Rules → Approved Capability → Windows Agent
The server can only request capabilities from the allowlist built into the signed agent.
⛔ Never
AI → Arbitrary PowerShell → Employee Laptop
No remote shell. No script payloads. No free-text commands.
✓
Jobs signed by ITIS · agent rejects unsigned or unknown capabilities
✓
Collectors are read-only. Benchmarks are time- and size-bounded.
✓
Results are schema-validated JSON. No personal files are read.
✓
mTLS between agent and server. Every job is in the audit trail.
